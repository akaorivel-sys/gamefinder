# GameFinder v20 — Recommendation Diagnosis

- Questions: 10
- Minimum answers to run: 7
- Catalog target: 10,000
- Recommendation dimensions: desired activity, solo/co-op/multi, complexity, commitment/playtime, budget, platform, Japanese, PC load, MOD preference, metadata certainty
- Result fields: match %, confidence %, reasons, cautions, Dossier/Steam links, compare shortlist
- Match and confidence are separated.
- Unknown metadata does not count as a positive match.
- High-certainty mode filters low-completeness Enriched Core entries more aggressively.
- Recommendations can be pushed directly into the v19 comparison engine.
- Internal root-relative link errors: 0

## Recommendation integrity
- The engine does not claim a universal 'best game'.
- It explains which user answers matched which verified game fields.
- It surfaces missing data as cautions instead of hiding uncertainty.
- Editorial Plus gets extra confidence because GameFinder has more verified editorial context for those entries.
